# Instapro

MVP социальной сети для обмена фотографиями (по мотивам Instagram).

Пользователи могут зарегистрироваться, войти в аккаунт, публиковать посты
с описанием и изображением, ставить и снимать лайки, удалять свои посты
и открывать страницы других пользователей с их постами.

## Функциональность

- **Регистрация и авторизация** — вход по логину и паролю, данные пользователя
  сохраняются в `localStorage`, после перезагрузки страницы сессия сохраняется.
  Есть возможность выйти из аккаунта.
- **Лента постов** — все посты загружаются с сервера; для неавторизованных
  пользователей лента доступна в режиме просмотра.
- **Добавление поста** — описание и изображение (картинка загружается
  на сервер через форму выбора файла, обратно приходит URL).
- **Лайки и дизлайки** — авторизованный пользователь может ставить
  и снимать лайк; на сервер отправляется соответствующий запрос.
- **Удаление поста** — доступно автору поста.
- **Страница пользователя** — по клику на имя или аватар открывается список
  постов конкретного пользователя.
- **SPA-навигация** — собственный роутер на константах страниц
  (`posts`, `user-posts`, `auth`, `add-post`, `loading`) без перезагрузки
  страницы.
- **Состояния загрузки** — на время загрузки данных показывается страница
  загрузки, у форм есть состояния «сохраняю…».

## Стек технологий

- **HTML5**, **CSS3** — вёрстка (включая готовый `ui-kit.css`)
- **JavaScript (ES6+)** — ES-модули, без фреймворков
- **Fetch API** — работа с REST API, промисы, обработка ошибок
- **Ванильный SPA-роутинг** — переключение страниц через `goToPage`
- **localStorage** — хранение сессии пользователя
- **Backend** — учебный API [webdev-hw-api.vercel.app](https://webdev-hw-api.vercel.app)
  с персональным ключом

## API

Используемый сервер: `https://webdev-hw-api.vercel.app/api/v1/<personalKey>/instapro`

| Метод   | Endpoint                  | Назначение                     |
| ------- | ------------------------- | ------------------------------ |
| `GET`   | `/instapro`               | Получить все посты             |
| `POST`  | `/instapro`               | Добавить пост                  |
| `DELETE`| `/instapro/<postId>`      | Удалить пост                   |
| `GET`   | `/instapro/user-posts/<userId>` | Посты конкретного пользователя |
| `POST`  | `/instapro/<postId>/like` | Поставить лайк                 |
| `POST`  | `/instapro/<postId>/dislike` | Снять лайк                  |
| `POST`  | `/api/user`               | Регистрация                    |
| `POST`  | `/api/user/login`         | Авторизация                    |
| `POST`  | `/api/upload/image`       | Загрузка изображения           |

Авторизованные запросы передают заголовок `Authorization: Bearer <token>`.

## Как запустить

1. Склонируйте репозиторий:
   ```bash
   git clone <адрес-репозитория>
   cd instapro
   ```
2. Если используется сборка (webpack), установите зависимости и соберите:
   ```bash
   npm install
   npm run dev      # режим разработки
   npm run build    # продакшн-сборка
   ```
   При использовании обычных ES-модулей (как в `index.html`) достаточно
   открыть `index.html` через Live Server или любой локальный сервер.
3. Откройте страницу в браузере.

> Изображения и запросы к API работают только с сетью — без интернета
> загрузка постов вернёт ошибку.

## Как пользоваться

1. Откройте приложение — лента постов загружается автоматически.
2. Чтобы публиковать и лайкать, войдите или зарегистрируйтесь
   на странице авторизации.
3. Нажмите «Добавить пост», выберите изображение, введите описание
   и опубликуйте.
4. Кликните по счётчику лайков, чтобы поставить или снять лайк.
5. Кликните по имени или аватару автора — откроется его страница с постами.
6. Свои посты можно удалить.
